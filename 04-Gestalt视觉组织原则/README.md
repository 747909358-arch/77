# 04-Gestalt视觉组织原则

## 项目定位
本项目研究 Gestalt（格式塔）视觉知觉组织原则，记录其概念定义、知觉机制、经典研究案例、信息图设计案例、设计分析与实践经验。

Gestalt 不是信息图形内容分类，不是 T/H/C/A/G 之外的第六类，也不是某一种图表类型。它是一组解释视觉元素如何被组织、分组、分离为图形与背景、形成整体结构的知觉原则，可用于信息图的布局、视觉编码、阅读路径与叙事组织。

## 原则数量与分类边界
Gestalt 原则不存在一个被所有研究传统共同接受的固定总数。本项目采用“9 项核心设计原则 + 扩展原则”的工作分类，便于设计研究与应用；这不是 Gestalt 心理学的唯一或穷尽清单。

9 项核心设计原则：
1. 接近律 Proximity
2. 相似律 Similarity
3. 连续律 Good Continuation
4. 闭合律 Closure
5. 图底组织 Figure–Ground
6. 共同命运律 Common Fate
7. 对称与秩序 Symmetry and Order
8. 简洁律 Prägnanz
9. 共同区域 Common Region

扩展原则至少记录：
- 连接律 Element Connectedness
- 平行原则 Parallelism
- 同步原则 Synchrony
- 统一连接 Uniform Connectedness

注意：图底组织研究与知觉分组原则相关但不完全等同；Prägnanz 通常作为更一般的组织倾向；共同区域、连接、同步等在现代综述中作为扩展分组线索讨论。目录中的“核心/扩展”是本库的研究管理方式，不宣称存在唯一标准分类。

## 研究与入库规范
每项原则至少记录：定义、原始研究/权威综述出处、知觉机制、成立条件与局限、经典示例、信息图案例、原图来源与许可、视觉组织分析、数据编码关系、阅读路径、读者测试、可迁移实践经验。

案例分析须区分：来源明确的事实、研究者解释、设计推论与待验证假设。不要把原则描述为无条件成立的绝对法则；需记录多个原则之间的竞争或协同。

## 推荐工作流程
概念与文献核验 → 经典知觉示例 → 信息图案例搜集 → 视觉结构拆解 → 设计实验/改版 → 可读性或识别测试 → 经验归纳与复用。

## 主要参考资料
- Wagemans, J. et al. (2012). [A century of Gestalt psychology in visual perception I: Perceptual grouping and figure-ground organization](https://pmc.ncbi.nlm.nih.gov/articles/PMC3482144/). Psychological Bulletin, 138(6), 1172–1217. DOI: 10.1037/a0029333.
- MIT 6.859, [Perception lecture: Gestalt Principles](https://vis.csail.mit.edu/classes/6.859/lectures/05-Perception.pdf). 教学材料列出图底、接近、相似、对称、连接、连续、闭合、共同命运，并说明 Prägnanz 倾向。
- [Gestalt Principles: Interactive Guide to Design Psychology](https://www.gestaltprinciples.com/). 设计导向的九项原则示例；作为设计教学资料使用，不作为 Gestalt 原则数量的学术定论。
