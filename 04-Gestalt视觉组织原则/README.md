# 04 Gestalt 视觉组织原则

## 项目定位
本项目研究 Gestalt（格式塔）视觉知觉组织原则，记录概念定义、知觉机制、经典研究案例、信息图设计案例、设计分析与实践经验。

Gestalt 不是信息图形内容分类，也不是 T/H/C/A/G 之外的第六类；它解释视觉元素如何被组织、分组、分离为图形与背景并形成整体结构。

## 原则数量与分类边界
Gestalt 原则不存在被所有研究传统共同接受的固定总数。本项目采用“9 项核心设计原则 + 扩展原则”的工作分类。

1. 接近律 Proximity
2. 相似律 Similarity
3. 连续律 Good Continuation
4. 闭合律 Closure
5. 图底组织 Figure–Ground
6. 共同命运律 Common Fate
7. 对称与秩序 Symmetry and Order
8. 简洁律 Prägnanz
9. 共同区域 Common Region

扩展原则包括连接律、平行原则、同步原则和统一连接。核心/扩展是本库研究管理方式，不宣称是唯一标准分类。

## 研究与入库规范
每项原则至少记录定义、研究出处、知觉机制、成立条件与局限、案例来源、视觉组织分析、数据编码关系、阅读路径、测试与可迁移经验。事实、研究者解释、设计推论与待验证假设分开标注。
