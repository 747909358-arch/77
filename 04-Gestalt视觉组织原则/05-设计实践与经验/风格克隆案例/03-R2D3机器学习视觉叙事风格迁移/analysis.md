# R2D3 机器学习视觉叙事：滚动式概念解释风格迁移

- 案例性质：风格克隆研究样例（研究型迁移方案，非已完成生成实验）
- 风格来源：R2D3 / Stephanie Yee 与 Tony Chu
- 来源链接：https://r2d3.us/
- 研究目标：提取可识别的视觉身份规则，并将其迁移到不同主题；不复制原作品的具体内容。

## 1. 来源作品与风格身份

R2D3 的《A Visual Introduction to Machine Learning》系列使用滚动触发的可视化、逐步构建的决策树和简洁文字解释机器学习；Part II 以滚动动画解释偏差—方差权衡，并获得 2019 Information is Beautiful Awards 奖项。

## 2. 风格 DNA（初步提取）

逐屏渐进揭示；单一视觉对象随滚动逐步变化；数据点/树结构作为主视觉；文字短而贴近图形；以节奏替代大段公式；交互/动画承担解释步骤。

## 3. 迁移任务

把复杂概念（例如城市热岛形成机制）改编成滚动式视觉讲解：每屏只引入一个因果/机制步骤，主图随滚动逐步构建，保持前后状态连续。

## 4. 核心保持与允许变化

- 必须保持：构图/组织机制、关键编码关系、视觉节奏及来源风格中承担身份识别的特征。
- 允许变化：主题对象、数据字段、文案、局部图形素材和适应新主题所需的布局细节。
- 不允许：复制原作数据、标识或独特内容而不注明来源；把视觉相似误报为原作者作品。

## 5. 风险与验收

**主要风险：** 动画可能让读者错过关键状态；移动端性能与无障碍需考虑；静态替代必须能表达核心内容。

**验收条件：** 每一步变化有明确语义；读者能复述机制；静态版本保留关键节点；动画不造成无意义装饰。
