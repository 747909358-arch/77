# 统计图形选择指南

| 读者任务 | 优先考虑 | 关键提醒 |
|---|---|---|
| 比较类别数值 | 柱状图/条形图 | 明确汇总口径，通常从零基线开始 |
| 看连续变量分布 | 直方图、箱线图、小提琴图、ECDF | 分别关注频数、摘要、密度形态、累计比例 |
| 看两个变量关系 | 散点图 | 相关不等于因果；留意重叠和非线性 |
| 看多个变量相关 | 相关矩阵热力图 | 明确相关系数类型和样本量 |
| 比较两个条件 | 哑铃图/坡度图 | 保持共同尺度，说明差值方向 |
| 看时间趋势 | 时间序列折线图 | 检查时间间隔、缺失和季节性 |
| 看总量与组成变化 | 堆叠面积图 | 中间系列不易精确比较 |
| 看多维记录模式 | 平行坐标图 | 处理量纲，减少过绘 |
| 看层级组成 | 矩形树图 | 面积比较精度有限，层级不可过深 |
| 看流向与转移 | 桑基图 | 校验流量，控制交叉连线 |
| 粗略比较多指标轮廓 | 雷达图 | 归一化和轴顺序会影响结论 |

## 选择步骤

1. 明确问题：比较、分布、关系、时间变化、组成、流向还是多变量探索？
2. 识别变量类型与记录粒度，检查样本量和缺失值。
3. 选择最直接、读数最准确的图形；复杂图形必须带来额外分析价值。
4. 检查尺度、基线、排序、分箱、归一化、颜色和图例。
5. 用替代图形交叉检查结论，并标注不确定性和数据来源。
