## 分类原则
1. 五大信息组织逻辑保持稳定：编年型（T）、层级型（H）、编目型（C）、字母表型（A）、地理图形型（G）。
2. ISOTYPE 是独立的基础视觉设计体系，不是第六种主类别，也不属于 02 的普通标签。案例可分析是否采用或受其启发，并链接 03。
3. 统计图形描述数据表达方式，不自动等于信息图整体主类别。
4. 区分事实、分析解释与待验证推测；数据必须记录来源、许可、字段、单位、时间范围与清洗过程。

## 工作方式
01—04 是通用研究与方法模块，05 是主题项目实践层。主题项目按调研、内容分析、数据搜集、数据集构建、叙事、视觉编码、测试、设计实施推进。
