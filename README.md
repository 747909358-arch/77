# 信息图形研究库

本仓库用于建立信息图形的数据逻辑、视觉编码与视觉叙事方法库，并通过案例持续验证、修订和扩展原则。整体分为通用研究方法层与具体主题项目实践层。

- [02-信息图形类型案例](./02-信息图形类型案例/README.md)：保存真实案例、来源、分析、数据集及标签体系；包含 ISOTYPE 视觉方法标签。

## 仓库的工作方式

**01—03 是可持续积累的通用研究方法库，04 是调用这些方法完成具体主题作品的项目实践层。**

一个主题项目不应直接从“选风格、画版面”开始，而应先明确研究问题和读者，再分析主题结构、搜集可追溯资料、构建数据、形成叙事，最后选择图形语言和视觉风格并测试实施。

## 核心分类原则

1. 五大信息组织逻辑保持稳定：编年型（T）、层级型（H）、编目型（C）、字母表型（A）、地理图形型（G）。
2. ISOTYPE、照片型、插画型、文字型、词云、混合型等属于视觉方法、表现风格或呈现特征标签，不新增五大主类别。
3. 统计图形类型描述数据表达方式，不自动等于信息图整体的主类别。
4. 区分可核实事实、分析解释与待验证推测。
5. 数据记录来源、许可、字段、单位、时间范围、清洗步骤和不确定性；不得编造数据或来源。
6. 通过案例与主题项目不断验证方法，并将可迁移结论回写到相应方法文档。

## 推荐工作流

确定主题 → 前期调研 → 主题内容分析（可借助大模型拆解，但事实须核验）→ 数据搜集 → 单列原子数据与多字段叙事数据集构建 → 叙事框架 → 视觉编码与风格系统 → 信息轮盘/可读性测试 → 设计实施与归档。
