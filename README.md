# 信息图形研究库

本仓库用于建立信息图形的数据逻辑、视觉编码与视觉叙事方法库，并通过案例持续验证、修订和扩展原则。

## 目录

- [01-信息图形数据逻辑](./01-信息图形数据逻辑/README.md)：按信息组织逻辑定义五类信息图形。此目录只保存方法论文本，不存放案例图片。
- [02-信息图形类型案例](./02-信息图形类型案例/README.md)：保存案例分析与类型方法总结。案例图片及来源信息归档于此。

## 研究与更新原则

1. **案例先行**：案例型结论必须能追溯到已收录案例；未有案例支持的内容标记为“待案例验证”。
2. **区分事实与解释**：记录可观察的图形结构、编码方式和文本层级，再提出设计解释，避免把推测写成事实。
3. **双向链接**：数据逻辑文档通过相对路径链接到案例文档；案例文档反向链接相关逻辑定义。
4. **版本迭代**：新增案例后，更新案例分析、共性原则、适用边界与反例；保留重要修订记录。
5. **图片归档**：图片只放在 `02-信息图形类型案例` 对应案例目录中；`01` 不复制图片。

## 案例提交建议

每个案例尽量提供：原图或高清截图、原始出处/URL、作者或机构、发布时间、可辨识的标题与说明。若图中含多个面板，尽量提供完整画面。
