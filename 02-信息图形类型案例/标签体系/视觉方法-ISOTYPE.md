# ISOTYPE｜视觉方法与图形语言

**标签维度：** 视觉方法 / 基础设计体系  
**标签名称：** ISOTYPE  
**建议检索写法：** `ISOTYPE`、`Isotype`、`国际文字图像教育系统`  
**标签性质：** 视觉表达方法标签，不是信息图形主类别，也不是单一图表类型。

## 1. 定义

ISOTYPE（International System of TYpographic Picture Education）是一套以标准化图画符号组织和传达社会统计与公共信息的视觉教育方法。它强调图形符号的一致性、可识别性、重复与组合规则，以及图像与文字说明之间的协作。

本标签用于识别作品是否采用或明确借鉴 ISOTYPE 的图形语言和信息表达原则。仅仅“使用了小图标”不足以判定为 ISOTYPE。

## 2. 识别线索

- 使用经过简化、标准化、可重复识别的图画符号代表对象或群体。
- 符号具有相对稳定的语义映射，同一符号在同一作品中保持一致。
- 数量或规模常通过重复符号的数量表达，而非任意放大单个图标；若采用比例缩放，应检查是否符合其表达规则。
- 图像符号与简短文字、标题、图例协同，帮助非专业读者理解统计或社会信息。
- 画面存在清晰的符号语法、排列规则和阅读顺序。

以上是分析线索，不应把单一特征当作充分条件；需结合作者说明、历史语境或作品整体结构判断。

## 3. 不应混淆

- **ISOTYPE ≠ 五大信息组织类别**：作品仍需按编年型、层级型、编目型、字母表型、地理图形型判断主类别。
- **ISOTYPE ≠ 图标风格**：普通装饰图标、emoji 或统一线性图标不自动构成 ISOTYPE。
- **ISOTYPE ≠ pictogram 的泛称**：应关注符号系统、数据表达规则及其教育/解释目标。
- **ISOTYPE ≠ 任何重复图案**：重复必须承担稳定的数据或信息含义。

## 4. 案例标注规则

案例分析中记录：
1. 主类别（T/H/C/A/G）及判断依据；
2. 标签：ISOTYPE；
3. 符号与对象/数量/类别的映射表；
4. 符号是否标准化、重复规则、组合规则和图例；
5. 文字说明与图像符号的分工；
6. 可确认的作者、来源、年代和历史语境；
7. 采用 ISOTYPE 的证据等级：作者明确说明 / 权威研究确认 / 视觉特征推断（待验证）。

若只是借鉴某些相似特征，标注“ISOTYPE-inspired（受 ISOTYPE 启发）”，不要直接认定为原典 ISOTYPE。

## 5. 分析模板

| 分析项 | 记录内容 |
|---|---|
| 符号对象 | 每种符号代表什么对象/群体 |
| 数量编码 | 一个符号对应多少单位，是否重复 |
| 语义一致性 | 同一符号是否始终表达同一含义 |
| 排列语法 | 行列、分组、方向、顺序和比较规则 |
| 文字协作 | 标题、注释、图例如何补充符号 |
| 读者任务 | 识别、计数、比较、理解社会关系等 |
| 证据等级 | 作者说明、文献确认或视觉推断 |

## 6. 与其他标签组合

可与编目型、编年型、文字型、统计图形、照片型等标签并用。标签之间描述不同维度，不意味着这些类型互为从属。

## 7. 参考资料与案例

正式案例应补充可核验的原始作品、作者/机构说明及学术来源。未核实的作品不得仅凭图标外观标为 ISOTYPE。
