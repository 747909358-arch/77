# 信息图形标签体系

本目录维护五大主类别之外的次级检索标签。标签描述作品采用的图形形态、数据关系、视觉方法、表现风格或主题领域，不取代五大信息组织逻辑。

## 标签维度

- **图形形态**：文字型、列表型、混合型、时间轴、地图、图表组合等。
- **数据关系**：比较、分布、层级、流向、相关、时序、空间关系等。
- **视觉方法/基础设计体系**：ISOTYPE 等具有独立图形语法和设计原则的方法。
- **表现风格/媒介**：照片型、插画型、摄影拼贴、图标系统、词云等。
- **主题领域**：自然、历史、经济、社会、科学等。

## 标签与主类别的关系

每个案例仍先判断 T/H/C/A/G 五大主类别，再添加一个或多个适用标签。一个案例可以同时使用 ISOTYPE、编目型、文字型等描述，但它们处于不同维度，不能相互替代。

## 新标签维护

新增标签前检查是否已有同义标签；写明定义、适用范围、排除项、识别特征和案例链接。标签名称应稳定、可检索，不以个人审美评价命名。
