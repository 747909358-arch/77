# 信息图形案例标签体系

本目录维护案例层面的次级检索标签，描述图形形态、数据关系、表现风格/媒介或主题领域，不取代五大信息组织逻辑。

- 图形形态：文字型、列表型、混合型、时间轴、地图、图表组合等。
- 数据关系：比较、分布、层级、流向、相关、时序、空间关系等。
- 表现风格/媒介：照片型、插画型、摄影拼贴、图标系统、词云等。
- 主题领域：自然、历史、经济、社会、科学等。

ISOTYPE 不属于本标签目录。案例若采用 ISOTYPE 或受其启发，应在分析正文记录证据与具体设计机制，并链接 [03-ISOTYPE信息图专项项目](../../03-ISOTYPE信息图/README.md)。
