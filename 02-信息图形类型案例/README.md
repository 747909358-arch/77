# 02 信息图形类型案例

本目录严格按五大信息组织逻辑归档。**每个案例文件夹与其主类别说明文档放在同一类别文件夹中**，案例只归属一个主类别；混合型、时间轴型、文字/列表型属于跨类别呈现特征，集中放在“06-跨类别呈现特征”，通过索引关联，不改变主分类。

## 目录

- [01-编年型](./01-编年型/README.md)：时间顺序与事件演进主导。
- [02-层级型](./02-层级型/README.md)：包含、从属与分类层级主导。
- [03-编目型](./03-编目型/README.md)：对象条目集合与共同属性主导。
- [04-字母表型](./04-字母表型/README.md)：固定字母、字符或约定符号系统主导。
- [05-地理图形型](./05-地理图形型/README.md)：地理位置与空间关系主导。
- [06-跨类别呈现特征](./06-跨类别呈现特征/README.md)：混合图表、时间轴、文字/列表等跨类别呈现方法。
- [标签体系](./标签体系/README.md)：案例次级标签，不替代五大主类别。
- [分析与入库规范](./分析与入库规范.md)：每个案例的统一分析与数据归档流程。

## 案例入库顺序

五类主类别判断 → 次级标签 → 案例特性分析 → 制作方法与工作流程 → 视觉编码 → 视觉叙事 → 基础数据集与来源归档。

ISOTYPE 是独立的基础视觉设计体系，不属于本目录的标签体系；参见 [03-ISOTYPE信息图专项项目](../03-ISOTYPE信息图/README.md)。
