## 双层分类原则

- **表现类型（17 类）**：回答案例视觉上属于哪种表现形式。
- **信息组织逻辑（T/H/C/A/G）**：回答信息按什么逻辑组织。两套维度不能互相替代。
- **次级标签**：记录词云、时间轴、混合图表等可检索特征。

## 案例入库规则

每个案例保留 `analysis.md` 与 `source.md`。原图放入 `原图/`、数据放入 `data/` 的前提是实际取得文件且许可允许；否则保留原始链接并明确标记缺失。事实、观察、推断和待核实内容分开记录。
