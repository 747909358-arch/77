# 02 信息图形类型案例

本目录保存案例图、出处、观察记录、分析结论及可获得的基础数据集。本目录是案例资产的唯一归档位置；[01-信息图形数据逻辑](../01-信息图形数据逻辑/README.md) 只通过文本链接引用案例，不重复保存图片或数据文件。

## 固定入库顺序（每张新图均执行）

### 01｜五大类别判断
先判断案例的主导信息组织逻辑，归入既有五类之一：编年型（T）、层级型（H）、编目型（C）、字母表型（A）、地理图形型（G）。混合结构需确定主类别并说明依据，不得新增第六类。

### 02｜次级标签判断
完成主类别判断后，再从 [信息图形标签体系](./标签体系/README.md) 选择适用标签。标签分为图形形态、数据关系、视觉方法/基础设计体系、表现风格/媒介和主题领域等维度。**ISOTYPE 是视觉方法标签，不是第六种主类别，也不等同于普通图标风格。**

### 03｜案例特性分析
描述信息目标、读者、内容单元/字段、版面布局、构图、色彩、字体、图形语法、信息密度、阅读入口和适用场景；区分客观观察与分析推断。

### 04｜制作方法与工作流程
尽可能还原资料采集、数据清洗、字段整理、分类排序、统计计算、图形选择、编码映射、版面搭建、校验和输出。无法确认的环节标记“推测”或“未知”。

### 05｜视觉编码提炼
分析位置、长度、角度、面积、颜色、形状、方向、纹理、连接、空间位置、尺度、文字和符号等视觉变量，说明它们对应的数据字段、表达关系及潜在误读。

### 06｜视觉叙事提炼
总结叙事主张、阅读路径、信息揭示顺序、对比/转折、视觉焦点、节奏和结论。

### 07｜归档与关联
每个案例建立独立目录，写入 `analysis.md` 和 `source.md`，并更新类型索引及相关理论链接。

### 08｜基础数据集入库
可合法获得的底层数据放入案例 `data/`；记录来源、许可、格式、字段、清洗过程及视觉编码映射。不可获得或不可再分发时，说明原因，不得编造或上传受限数据。

## analysis.md 统一模板

### A. 基本信息
- 案例编号 / 名称：
- 主类别（T/H/C/A/G）与判断依据：
- 次要/混合结构：
- 次级标签及维度：
- 作者 / 机构 / 来源 URL / 发布时间：
- 图片文件 / 数据集状态：

### B. 图形特性
信息目标、目标读者、字段关系、布局构图、视觉风格、色彩字体、图形语法、信息层级、密度、优势与局限。

### C. 制作方法与流程
资料采集、数据清洗、字段组织、统计计算、图形选择、编码映射、版面构建、校验输出；标注工具及事实/推断边界。

### D. 视觉编码
位置、长度、角度、面积、颜色、明度、形状、符号、方向、连接、空间位置、尺度及其字段映射、比较任务和误读风险。

### E. 视觉叙事
核心主张、阅读路径、信息揭示顺序、转折对比、视觉焦点、节奏、修辞策略与可迁移方法。

### F. 基础数据集
数据文件、来源许可、格式字段、记录粒度、原始/清洗版本、处理步骤、编码映射；未获得时记录原因。

### G. 归纳与复用
个案策略、可迁移原则、适用条件、反例和待验证问题。
