# 02 信息图形类型案例

本目录保存案例图、出处、分析、数据集及案例标签。每个新案例依次完成：五大类别判断（T/H/C/A/G）→ 次级标签 → 特性分析 → 制作流程 → 视觉编码与叙事 → 数据集归档。

ISOTYPE 不再是本目录的标签。若案例采用 ISOTYPE 或受其启发，应在分析正文中说明具体符号与编码机制、证据等级，并链接 [03-ISOTYPE信息图专项项目](../03-ISOTYPE信息图/README.md)。

案例分析应区分客观观察、来源可证事实和分析推断；数据记录来源、许可、字段、单位、时间范围、清洗步骤与不确定性。不可获得或不可合法再分发的数据不得编造或上传。
