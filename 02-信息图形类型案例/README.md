## 案例入库规范

建议每个案例建立独立子目录，命名为 `案例编号-简短名称`，目录内包括：
- `source.md`：原始出处、作者/机构、标题、发布时间、访问日期、原始 URL、版权/许可信息。
- 原图文件：尽可能保存完整画面及必要的局部细节；文件名含案例编号。
- `analysis.md`：客观观察、结构拆解、视觉编码、信息架构、叙事路径、优缺点与适用边界。

## 迭代规则

每新增案例，先写观察记录，再归纳跨案例共性；只有被多个案例支持或有明确理论依据的内容才提升为稳定原则。单一案例的独特做法标记为“个案策略”。发生修订时，在相关类型文档的“版本记录”中说明依据，并同步更新 01 目录中的逻辑定义和双向链接。
