# 基础数据集数据字典

## 01 单列原子数据

单列数据用于建立主题中某一类原子观测值/条目的全集。每个数据文件应有明确且单一的变量定义。

| 字段名 | 含义 | 类型 | 单位/格式 | 一条记录代表什么 | 来源 | 缺失值规则 |
|---|---|---|---|---|---|---|
| value |  |  |  | 一个独立观测值/条目 |  |  |

要求：
- 一行只表示一个观测值/条目。
- 单列只表达一个明确定义的变量；不要把名称、日期、类别、数值等不同含义混在一个字段里。
- 如果是名义数据，记录类别名称；如果是量化数据，记录数值及单位；如果是文本数据，说明文本片段的粒度；如果是图像数据，使用文件路径/资产 ID，并保留来源与版权。
- 多种类型的数据不要伪装成同一种数据；必要时分文件保存。

## 02 多字段叙事数据

| 字段名 | 含义 | 类型 | 单位/格式 | 主键/关联键 | 来源 |
|---|---|---|---|---|---|
| id | 唯一记录标识 | string |  | 主键 |  |
|  |  |  |  |  |  |

多列数据用于表达关系，例如“名称 + GPS 坐标”定位地图地点，“年份 + 指标值”表达时间变化，“对象 + 类别 + 数量”支持分类比较。每列均须独立定义，主键和关联键须稳定，不能只为视觉效果拼接无关字段。

## 质量检查
- 字段是否单一、明确、可解释？
- 每行记录粒度是否一致？
- 单位、日期格式、编码和缺失值是否统一？
- 是否保留原始数据与清洗数据？
- 是否记录来源、许可、采集日期和转换步骤？
- 视觉编码是否能回溯到字段？
