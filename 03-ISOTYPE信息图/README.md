# 03 ISOTYPE 信息图

**项目定位：独立的基础视觉设计体系与信息表达方法专项研究。** ISOTYPE 不属于五大信息组织类别，也不是案例库中的普通标签。

研究范围包括历史与人物、设计哲学与社会教育、符号系统与视觉语法、数量编码、版式系统、经典作品、当代转化与实践工作流。核心关注标准化图画符号如何与数据、文字和排列规则结合，形成可理解的信息表达。

## 核心原则
- 符号具有稳定语义映射，同一作品内保持一致。
- 重复符号可表达数量，但必须明确一个符号代表的单位。
- 图像、文字、标题、图例和版式共同构成信息系统。
- 普通图标、emoji 或重复装饰图案不自动构成 ISOTYPE。
- 区分原典归属、研究文献确认、受 ISOTYPE 启发和仅视觉相似待验证。

## 研究模块
1. 历史与人物
2. 设计哲学与社会教育
3. 符号系统与视觉语法
4. 数量编码与信息组织
5. 版式与视觉系统
6. 经典作品案例
7. 当代继承与转化
8. 实践工作流

## 与其他模块的关系
01 判断信息组织逻辑；02 归档真实案例；03 研究 ISOTYPE 视觉体系；04 提供统计图形原理；05 在主题项目中综合调用。作品仍按 T/H/C/A/G 判断主类别，ISOTYPE 是可跨类别调用的视觉方法体系。
