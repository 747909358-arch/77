# 公开数据

## S02｜OWID 河流入海塑料估计

- 图表与方法说明：https://ourworldindata.org/grapher/plastic-entering-ocean?measure=total
- CSV：https://ourworldindata.org/grapher/plastic-entering-ocean.csv?v=1&csvType=full&useColumnShortNames=false&measure=total
- Metadata JSON：https://ourworldindata.org/grapher/plastic-entering-ocean.metadata.json?v=1&csvType=full&useColumnShortNames=false&measure=total
- 原始研究：Meijer et al. (2021), *More than 1000 rivers account for 80% of global riverine plastic emissions into the ocean*, Science Advances, 7(18), eaaz5803.
- 指标年份：2019；单位：tonnes/year。
- 重要限制：模型估计而非逐河直接测量；OWID 页面引用的补充材料包含国家层级统计；主要针对大于约 0.5 cm、漂浮或近水面的较大塑料；不包括微塑料、河床塑料或被水坝拦截的塑料；不确定性显著。
- 下载状态：待执行。下载后先确认实体字段是否为国家/地区及其空间标识；在确认前不绘制河流级线图。保留原始文件及 metadata，不要覆盖。
