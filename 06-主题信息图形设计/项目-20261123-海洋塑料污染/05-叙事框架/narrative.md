# 05 叙事框架

## 核心叙事主张
海洋塑料污染与陆地生产消费和废弃物管理相连；理解塑料从来源到海洋的路径、数据证据及其局限，才能找到有效的治理节点。

## 读者问题
- 首先：海洋塑料污染从哪里来？
- 接着：塑料通过什么路径进入海洋，哪些地方有较高的入海估计？
- 然后：我们如何知道海岸上有哪些垃圾？这些监测能说明什么、不能说明什么？
- 最后：哪些环节可以阻断污染路径？

## 信息顺序

| 顺序 | 内容单元 | 使用字段/证据 | 读者获得的信息 |
|---|---|---|---|
| 1 引入 | 塑料生命周期与污染问题 | UNEP 定义/综述 | 这是从生产消费到环境管理的系统问题 |
| 2 来源 | 塑料废弃物如何泄漏 | 来源分类与文献 | 污染不只来自海上 |
| 3 路径与地图 | 国家层级河流入海模型估计 | S02 国家/地区实体、估计量 | 不同国家/地区的估计存在差异；数字是模型估计 |
| 4 现场窗口 | 海岸线垃圾监测 | S03 日期、点位、类别、计数、努力量 | 岸线监测可揭示局部垃圾类型和变化，但不是全球海洋存量 |
| 5 影响与行动 | 生态影响机制和治理节点 | UNEP/同行评审文献 | 从源头减量、管理、拦截到监测，治理需多环节协同 |

## 叙事结构
- 主线：来源 → 路径 → 空间证据 → 生态影响 → 治理。
- 支线：宏观塑料与微塑料的区别；模型估计与现场观测的区别。
- 证据链：每个关键陈述对应来源 ID；数字旁标注年份、单位、方法和范围。
- 不确定性：模型估计误差、监测覆盖偏差、不同粒径定义、不同研究的时间与空间差异。

## 字段关系
- 国家/地区名称 + 国家代码/边界 + 估计量 = 国家层级河流入海估计地图；若要绘制具体河流路径，需另找河流级数据。
- 监测点 + 日期 + 垃圾类别 + 计数 + 调查努力量 = 海岸线监测比较。
- 来源类别 + 输送路径 + 治理措施 = 污染路径与干预节点图。
