# 06 主题信息图形设计

本目录是主题项目实践层，综合调用 01 信息组织逻辑、02 案例研究、03 ISOTYPE 基础视觉设计体系、04 Gestalt 视觉组织原则与 05 统计图形知识，围绕具体主题完成从调研到设计交付的完整项目。

项目流程：01 前期调研 → 02 主题内容分析 → 03 数据搜集 → 04 基础数据集 → 05 叙事框架 → 06 视觉编码 → 07 信息轮盘测试 → 08 设计实施。

主类别仍从 T/H/C/A/G 中判断；ISOTYPE 与 Gestalt 可作为视觉体系和组织方法调用，但不新增主类别。数据必须记录来源、许可、口径、单位、时间范围和清洗过程；大模型协助分析但不能替代事实核验。

项目目录按 `项目-YYYYMMDD-主题简称` 命名。现有海洋塑料污染项目完整保留。
