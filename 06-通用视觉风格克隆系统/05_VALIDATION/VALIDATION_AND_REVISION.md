# 验收、诊断与修订

## 1. 六维验收

分别检查：

1. 风格保持：核心表现特征与组织关系是否成立。
2. 内容符合：主体、数量、动作、对象及关系是否正确。
3. 锁定保持：原内容、构图、文字和资产是否按要求保留。
4. 图文结构：信息完整、文案准确、层级与阅读有效。
5. 技术交付：文件可用性、格式、尺寸、数量及独立性。
6. 系列一致性：风格、角色与资产分别保持必要连续性。

单项状态：`pass` / `fail` / `unknown` / `not_applicable`。尚未生成是 `not_generated`；有图未检查是 `unreviewed`。未知不算通过，必须条件失败不能由其它维度优点抵消。

## 2. 诊断层级

- 参考误读/身份错误：返回参考和核心分析。
- 内容不成立：重建主体、动作、器物与环境关系。
- 规则失配、遗漏或冲突：修正条件、依赖和有效指令。
- 模型未执行：检查真实输入、后端能力和编辑方式。
- 局部表现失衡：修改最小关联集合，保护其它要求。
- 文案、数量、格式错误：修正交付，不以审美解释技术失败。

## 3. 修订闭环

指定有效基线 → 定位偏差 → 确认目标变化 → 检查关联影响 → 确定允许范围与保护项 → 修改 → 重验目标和非目标变化 → 保存版本。

未验收图像不得自动升级为新基准。保留最近有效版本，防止漂移累积。

## 4. 状态判定

只有所有必须条件通过且无阻断性未知项，才能对该交付范围报告通过；有未决项保留 `indeterminate` 并列明范围。

## 5. 测试类型

- 同主题复现：同一主题多次生成，观察风格稳定性。
- 跨主题迁移：同一档案用于不同主题，观察核心关系是否保留。
- 跨后端适配：同一档案编译到不同模型，分别记录后端能力与结果；不要求像素级相同。
