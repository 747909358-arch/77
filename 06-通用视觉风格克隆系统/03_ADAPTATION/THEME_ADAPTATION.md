# 主题自适应与迁移

## 1. 执行链

主题解析 → 调用核心规则 → 分配关系角色 → 设计主体与环境 → 协调色光与表现 → 组织图文与密度 → 复核边界与冲突。

核心是重新设计承担关系的要素，而不是沿用物料清单或机械替换名词。

## 2. 主题解析

解析对象/主体、数量、身份特征、动作或状态、主体关系、环境、叙事意图、受众、文案、画幅、交付格式和项目锁定项。

## 3. 适配流程

1. 载入指定且已核验的 `style_profile`。
2. 读取有效核心规则与条件规则。
3. 将新主题映射到主体、空间、焦点、辅助元素、视觉路径等关系角色。
4. 根据新对象结构重新设计构图、尺度、色光、材质、密度和张力。
5. 执行关联复核与规则冲突检查。
6. 生成适配后的 `image_task` 和四版本提示词。

## 4. 关联复核表

| 变化入口 | 优先检查 |
|---|---|
| 主体身份、数量、动作 | 身份与造型、动作与器物、群组与尺度、密度与锚点 |
| 环境、位置、视角 | 空间接触、遮挡、前后景、光线、重心与路径 |
| 色彩、明暗 | 色彩角色、材质显现、边缘、注意力与对照 |
| 描绘、边缘、纹理 | 造型机制、局部展开、媒介统一、密度与焦点 |
| 标题、文字量、字体 | 语义完整、图文比例、版式、层级、阅读顺序 |
| 画幅、裁切、数量 | 构图可用性、必要内容保留、独立输出与系列关系 |
| 核心身份 | 所有有效核心及其依赖；必要时建立派生档案 |

## 5. 单变量迭代

孤立问题采用单变量修改；关系本身错误时修改最小关联集合。每次记录基线、目标变量、保护项、变更、目标验收和非目标副作用。不得整体重写后无法判断因果。
