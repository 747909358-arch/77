# 视觉语言基础与 SC-IMG 的衔接

本文件将用户资料中的视觉语言课程内容接入 SC-IMG，不替代十三分系统，也不新增总控。

## 1. 视觉语言的作用

视觉语言是把设计判断转换为可观察、可操作、可复核的视觉变量。系统不能停留在“温柔、梦幻、高级、有故事感”等感受词，而应说明画面通过什么视觉结构产生这种感受。

## 2. 光线语言

按三个核心变量分析：

- **方向**：决定阴影落位、立体感和戏剧性；需说明相对于主体/观察方向的位置。
- **光质**：硬光、软光或混合光，需观察阴影边缘与过渡。
- **光比**：描述亮部与暗部的对比关系。

还需记录光线的叙事功能、空气感、环境反射，以及它如何统一空间。方向、光质、光比共同构成光线语言，不应只写“柔和光”或“电影光”。

## 3. 色彩语言

色彩分析至少区分三个层次：

- **物理层**：色相、明度、饱和度、冷暖、面积与区域分布。
- **心理情感层**：色彩如何参与情绪与注意力组织；这是基于视觉语境的解释，需标记为 inference。
- **符号文化层**：色彩在特定文化和题材中的象征含义；不可把某一文化解释当成普遍事实。

输出应描述主色、辅色、强调色、比例、区域和关系，而非只列色名。

## 4. 构图语言

观察视觉重量、重心、引导线、留白、前中后景、遮挡、层次和观看路径。构图判断需要说明元素如何组织注意力，而非仅使用“居中、三分法、对称”等标签。

## 5. 风格与材质语言

风格不只是技法清单，也是一种叙述者身份声明：它影响作品以什么身份向观看者说话，以及观看者与作品之间形成什么关系。

材质是风格语言的延伸，可通过触觉隐喻表达质地、历史积累和物理价值感。分析必须区分真实可见的媒介/表面特征与对其叙事意义的推断。

## 6. 结构性叙事

把叙事意图转化为画面结构：主体与环境关系、视觉张力、注意力路径、停留点、对照关系和余韵。叙事不能只写成主题故事梗概；要说明观看者先看到什么、沿什么路径移动、在哪里停留，以及哪些信息被有意保留或省略。

## 7. 与 SC-IMG 的映射

| 视觉语言知识 | SC-IMG 对应位置 |
|---|---|
| 光线方向、光质、光比 | B2 光线系统 |
| 色彩物理/心理/文化层 | B1 色彩系统；心理与文化解释须标记 inference |
| 视觉重量、重心、引导线、留白 | B3 空间构图、B4 尺度关系、E2 视觉锚点 |
| 叙述者身份、艺术语境 | A1 风格本体、narrative_stance |
| 材质触觉隐喻 | C4 材质与纹理，关联 C1/C3 |
| 主体与环境的叙事关系 | D1 主体设计、E3 张力 |
| 注意力路径、停留点、余韵 | E2 视觉锚点、E3 张力、生成用 narrative 字段 |

## 8. 运行要求

每项输出都区分观察与解释；任何色彩象征、文化来源、叙事立场或艺术史判断，在缺乏证据时不得写成确定事实。若参考图无法支持某个判断，标记 pending，并在必要时请求用户补充多张参考或背景信息。
