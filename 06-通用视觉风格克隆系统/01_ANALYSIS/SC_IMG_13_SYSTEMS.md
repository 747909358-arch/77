# SC-IMG 五总控十三分系统

十三项在档案中完整保留，但按参考与任务启用。每项状态为 `active`、`inactive`、`not_applicable`、`pending`。待判断不能擅自标成不适用。

| 总控 | 分系统 | 观察重点 | 规则与检查重点 |
|---|---|---|---|
| A 美学定位 | A1 风格本体 | 参考范围、共同特征、独特偏离、表达立场 | 风格身份、核心关系、适用/不适用范围；新图是否保留识别机制 |
| B 视觉形式 | B1 色彩 | 色域、明度、饱和度、冷暖、区域分布 | 谁主导、谁强调、怎样分配；检查主导关系与统一性 |
| B 视觉形式 | B2 光线 | 来源、软硬、明暗组织、叙事功能 | 照明如何服务形体和氛围 |
| B 视觉形式 | B3 空间构图 | 重心、遮挡、前后景、留白、视线路径 | 各层如何连接，位置是否锁定/可重排；检查接触、遮挡和重心 |
| B 视觉形式 | B4 尺度关系 | 主体/环境、群组/单体、文字/图像比例 | 保持何种相对大小，标明测量口径；检查尺度差与可辨认性 |
| C 绘画表现 | C1 绘画语言 | 线描、笔触、概括方式、形体关系 | 形体由什么方式建立；避免未经允许的默认写实或三维塑形 |
| C 绘画表现 | C2 边缘控制 | 清晰、柔化、断裂、消隐及分布 | 哪些边缘交代对象，哪些融入空间；检查无意义硬边 |
| C 绘画表现 | C3 完成度控制 | 充分描绘、简化、省略的区域 | 按区域描述描绘等级与功能，不给伪精确百分比 |
| C 绘画表现 | C4 材质与纹理 | 媒介颗粒、纸绢/胶片/印刷感、表面差异 | 纹理来源、位置、强弱；检查是否遮蔽形体、文字或必要信息 |
| D 内容生成 | D1 主体设计 | 人物、产品、建筑等主体及行动/关系 | 身份、造型、数量、动作、器物与场景相容条件 |
| E 视觉控制 | E1 信息密度 | 信息单元数量、细节分布、疏密节奏 | 高/中/低密度区与必须信息；检查完整性和层次 |
| E 视觉控制 | E2 视觉锚点 | 主焦点、次焦点、发现顺序、停留位置 | 锚点由谁承担、为何可见、怎样避免争夺 |
| E 视觉控制 | E3 视觉张力 | 尺度、方向、纵深、疏密、明暗对照 | 哪些要素形成何种对照、服务何种主题 |

## 补充处理

字体、品牌、系列连续性按需扩展，不另增总控：文字语义属于 D1；图文布局比例属于 B3/B4；字形表现属于 C；阅读密度与强调属于 E。

## VSCF 说明文档的十三项对应

VSCF 说明文档按独立清单列出风格本体、色彩、光线、构图、尺度、绘画语言、边缘、完成度、信息密度、材质纹理、主体设计、视觉锚点、张力。运行分组以 SC-IMG 五总控十三分系统为主；两份资料的术语差异应保留映射，不改变各项含义。
