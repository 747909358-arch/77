# 风格档案库

每种风格使用唯一 `style_id`，例如 `STYLE-0001`。推荐目录：

```text
STYLE-0001/
  reference/
  analysis/
  rules/
  profile.json
  prompts/
  tasks/
  reviews/
  changelog.md
```

## 管理原则

- 风格档案与图像任务分离。
- 原始参考图和证据应保留来源标识。
- 单图档案不得自动升级为艺术家/流派整体档案。
- 修改核心时创建派生档案并记录父 ID。
- 主题变化只创建新任务，不覆盖原风格档案。
- 未验收结果不得成为默认参考基准。
