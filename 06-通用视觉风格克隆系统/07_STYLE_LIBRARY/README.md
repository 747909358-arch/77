## 管理原则

- 风格档案与图像任务分离。
- 原始参考图和证据应保留来源标识与许可信息。
- 单图档案不得自动升级为艺术家/流派整体档案。
- 修改核心时创建派生档案并记录父 ID。
- 主题变化只创建新任务，不覆盖原风格档案。
- 未验收结果不得成为默认参考基准。
- 未核实许可的原图不复制；来源链接不等于图片文件已托管。
- 只有实际图像完成 SC-IMG 六维验收后，才可将 draft 升级为 validated。
