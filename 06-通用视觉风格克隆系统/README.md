# 通用视觉风格克隆系统（SC-IMG Pro）

**视觉风格分析、风格 DNA 提取、主题自适应与提示词编译系统**  
版本：0.1.0（基础运行包）

## 系统目标

依据真实参考图提取具有识别作用的视觉特征及其组织关系，形成可保存、可调用、可迁移、可验证的风格档案。系统复制的是视觉生成机制，不是原图的物料清单。

## 三种启动场景

1. **上传启动**：将本目录中的 `START.md`、核心规范和所需模板上传到网页版大模型，输入“启动 SC-IMG Pro”。
2. **仓库启动**：让模型读取本目录的 `START.md`，再按依赖清单加载文件。
3. **记忆启动**：模型恢复轻量记忆后，执行 `00_CORE/MEMORY_BOOTSTRAP.md`。记忆不是完整规范；未读取文件时不得报告 `READY_FULL`。

## 核心运行模式

- `extract`：从真实参考提取风格并建立档案。
- `apply`：调用已有档案，适配新主题，输出提示词或按要求生成图像。
- `revise`：针对指定当前作品做有边界的修订。
- `audit`：审查参考分析、档案、提示词或输出。

## 系统组成

- `00_CORE`：系统定位、启动协议、术语和记忆启动卡。
- `01_ANALYSIS`：参考身份、观察程序、十三分系统。
- `02_STYLE_DNA`：风格 DNA、规则编码、档案数据契约。
- `03_ADAPTATION`：主题解析、关联复核、冲突处理。
- `04_PROMPT_COMPILER`：四版本输出规范与编译校验。
- `05_VALIDATION`：六维验收、修订闭环、测试用例。
- `06_BACKEND`：模型后端能力记录与适配原则。
- `07_STYLE_LIBRARY`：风格档案库约定。
- `08_TEMPLATES`：JSON 模板。
- `09_CHANGELOG`：版本记录。

## 重要边界

- 系统不含预设画风；每种风格必须由实际参考图或经核验的风格档案提取。
- 单图只支持作品级判断，不自动代表某位艺术家、流派或整个时期。
- JSON 是数据结构，不等于图像模型原生 API；必要时必须转译为后端实际接受的自然语言或接口格式。
- 同一提示词不保证像素级复现；风格保持必须通过真实输出验收。
- 观察、推断、用户要求、设计选择必须分开标记。

## 快速启动

读取本目录的 `START.md` 并按其依赖清单执行。不要只总结文件；应初始化为可执行状态并报告真实加载状态。
