# 主题信息图形项目模板

复制本目录为 `项目-YYYYMMDD-主题简称`，不要直接在模板目录里开展正式项目。

## 文件结构

```text
项目-YYYYMMDD-主题简称/
├── README.md
├── 01-前期调研/
│   ├── brief.md
│   ├── 受众与研究问题.md
│   └── 来源地图.md
├── 02-主题内容分析/
│   ├── 内容分析.md
│   ├── 概念与分类.md
│   └── 大模型协作记录.md
├── 03-数据搜集/
│   ├── 公开数据/
│   ├── 文本与文献/
│   ├── 自建数据/
│   └── 来源与许可登记.csv
├── 04-基础数据集/
│   ├── 01-单列原子数据/
│   ├── 02-多字段叙事数据/
│   ├── data-dictionary.md
│   └── cleaning-log.md
├── 05-叙事框架/
│   ├── narrative.md
│   └── 字段关系图.md
├── 06-视觉编码/
│   ├── encoding-map.md
│   ├── style-board.md
│   └── sketches/
├── 07-信息轮盘测试/
│   ├── test-plan.md
│   └── test-results.md
└── 08-设计实施/
    ├── production-log.md
    ├── deliverables.md
    └── source-files/
```

## 项目入口 README

- 主题：
- 项目负责人 / 协作者：
- 项目状态：
- 目标受众：
- 核心问题：
- 主张 / 核心信息：
- 主类别候选（T/H/C/A/G）及依据：
- 次级标签（如 ISOTYPE、照片型、文字型等）：
- 数据状态：
- 设计规格与交付形式：
- 当前风险与待验证问题：

## 完成定义

项目至少完成：研究问题明确、来源可追溯、数据字段有定义、叙事逻辑成立、视觉编码可解释、测试问题有记录、最终文件可打开且版本可追溯。
