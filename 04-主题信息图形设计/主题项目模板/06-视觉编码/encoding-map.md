# 06 视觉编码映射表

先确定数据字段和读者任务，再选择视觉通道。一个编码必须说明字段、视觉变量、读者可读出的关系和误读风险。

## 可选图形语言与方法
- 点、线、面、体及其位置、长度、面积、角度、宽度、距离。
- 色相、明度、饱和度；需说明分类、顺序或强调含义。
- 行距、字距、字号、字重、字体与文本层级。
- 图像、照片、插画、图标、符号系统。
- 统计图形：从 03 选择，并说明数据与统计条件。
- ISOTYPE：仅在符号系统和重复/组合语法有依据时采用并标注。
- 版式、留白、分组、阅读路径和空间层级。

## 视觉风格标签候选
文字型 / 照片型 / 插画型 / 词云 / 数据图表型 / 混合型 / ISOTYPE / 其他。
这些标签描述表现方式或视觉方法，不替代 T/H/C/A/G 主类别。

## 编码校验
- 定量变量是否使用可比较的尺度？
- 面积/半径、颜色顺序和图例是否准确？
- 同一符号是否保持语义一致？
- 是否有色觉、字号、对比度和阅读顺序问题？
- 视觉效果是否遮蔽数据不确定性？
