# 05 叙事框架

## 核心叙事主张
用一句话写出作品希望读者理解的核心信息：

## 读者问题
- 读者首先想知道什么？
- 读者最终应理解什么？

## 字段关系
解释哪些字段组合形成什么信息。例如：名称 + GPS = 地图上的地点；年份 + 数值 = 时间序列；类别 + 数量 = 分类比较。
