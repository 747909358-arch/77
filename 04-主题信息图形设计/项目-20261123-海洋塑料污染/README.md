# 主题项目｜海洋塑料污染：从陆地到海洋

- 项目编号：04-20261123-MP
- 项目状态：立项与调研框架已建立；数据下载、清洗、验证和视觉测试待执行
- 主题方向：A｜海洋塑料污染——从陆地到海洋
- 视觉表达：综合型（地图 + 统计图表 + 图形符号）
- 目标受众：公众科普
- 主要语言：中文（数据源保留原始语言和字段）
- 研究尺度：全球背景为主；选取有可比数据的区域/河流/海岸案例作局部放大
- 暂定主叙事：塑料废弃物如何从陆地与人类活动进入水环境，经河流和海岸路径抵达海洋，在海洋环境中分布，并对生态系统形成压力；最后讨论源头减量与治理。

## 核心研究问题

塑料废弃物如何从人类生产、消费和废弃管理环节进入河流与海洋？现有证据能告诉我们哪些来源、输送路径和空间分布？这些证据有哪些边界？哪些治理环节能够阻断污染路径？

## 当前关键约束

1. 不把“进入水生生态系统”的总量直接写成“进入海洋”的总量；UNEP 的 19–23 Mt/年表述覆盖湖泊、河流和海洋等水生生态系统。
2. 河流入海估计采用模型估算，不能标为每条河流的直接实测值；OWID 页面明确说明其主要涵盖大于约 0.5 cm、漂浮或近水面的较大塑料，并排除微塑料、河床塑料和被水坝拦截的塑料。
3. NOAA MDMAP 是标准化海岸线垃圾监测项目，适合研究海岸线垃圾类型和时间变化，不等同于全球海洋塑料浓度监测。
4. 不同数据集的单位、时间、空间覆盖、采样方法和对象不同，未经口径校验不得拼接或排名。
5. 当前项目尚未下载并验证原始数据文件；任何图表数值均须在数据入库后再计算。
