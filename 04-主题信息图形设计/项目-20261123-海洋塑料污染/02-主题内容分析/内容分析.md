# 02 主题内容分析

## 主题定义
本项目聚焦塑料废弃物进入水环境并最终抵达海洋的过程，关注人类活动与废弃物管理、陆地输送路径、河流入海估计、海岸线垃圾观测、海洋生态影响和治理节点。

## 概念链
塑料生产与消费 → 使用后废弃 → 收集/处理/回收或管理不善 → 陆地环境泄漏 → 雨水径流/河流/沿岸与海上活动 → 海洋环境中的漂浮、沉积、破碎与迁移 → 生物摄入/缠绕/栖息地影响 → 源头减量与治理。

此链条是研究组织框架，不表示所有塑料都沿同一条路径，也不暗示所有路径占比已知。

## 核心对象与关系
- 对象：塑料产品、废弃物、国家/区域统计单元、河流流域（若另有数据）、海岸监测点、海域、海洋生物、治理措施。
- 关系：来源、输送、空间位置、时间、类别、数量、监测方法、影响机制、治理干预。
- 关键区分：宏观塑料/微塑料；模型估算/现场监测；河流入海/海岸垃圾/海洋存量；全球估计/区域样本。

## 信息组织逻辑判断
- 主类别候选：G 地理图形型（建议作为整张作品的主骨架）。
- 判断依据：核心问题涉及污染来源与路径的空间分布，地图承担主要组织和定位作用。
- 次要结构：T 编年型可用于政策/治理时间线；C 编目型用于塑料来源和垃圾类型分类；H 层级型用于来源—路径—影响关系。
- 最终类别须在完成数据盘点和草图后复核；若地图不再承担主导阅读结构，应调整主类别。

## 标签候选
- 图形形态：混合型、地图型、流程图、统计图表型。
- 数据关系：空间分布、流向、比较、分类、时间变化。
- 视觉方法：ISOTYPE-inspired（若建立稳定符号语法并经验证）；不因使用小图标就直接标为 ISOTYPE。
- 表现风格：图形符号型、少量照片辅助、公众科普型。
- 主题领域：海洋、环境、污染、塑料废弃物。

## 内容取舍
**必须呈现：** 来源与路径、河流入海估计及不确定性、空间案例、海岸线垃圾监测的意义与局限、生态影响机制、治理节点。

**可选呈现：** 塑料生产消费背景、政策时间线、不同聚合物类型、微塑料研究进展。

**暂不纳入：** 将所有海洋污染物混为一谈；缺乏一致口径的全球海洋塑料总量排名；没有来源的“塑料瓶分解年限”数字；把某一动物个案泛化为全部物种风险。

## 证据状态
- UNEP 报告可支持全球问题框架及影响/治理综述。
- OWID 河流入海指标为 2019 年国家层级模型估计（OWID 页面所列来源包含国家层级统计），主要针对大于约 0.5 cm、漂浮或近水面的塑料；不可直接解释为逐河实测；其不确定性不可忽略。
- NOAA MDMAP 提供标准化岸线垃圾监测框架与公开数据入口，但不是全球海洋浓度调查。
- 具体数据文件、字段、许可证及下载版本仍需实际下载核验。
