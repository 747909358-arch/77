# 03 统计图形分析

本目录建设为统计图形与统计方法知识库，解释数据如何经过统计处理并转化为视觉表达。它为 [01-信息图形数据逻辑](../01-信息图形数据逻辑/README.md) 提供统计方法支撑，为 [02-信息图形类型案例](../02-信息图形类型案例/README.md) 提供图表原理、编码和解读依据，并由 [04-主题信息图形设计](../04-主题信息图形设计/README.md) 在具体项目中调用。

> 本目录的统计图形模块不改变 T/H/C/A/G 五大信息组织类别。统计图形描述数据表达方式；ISOTYPE 等描述视觉方法；主题项目需要综合选择。

## 统一分析模板

新图形条目使用[统计图形分析模板](./统计图形分析模板.md)，记录数据条件、统计原理、视觉编码、阅读解释、适用边界、制作流程和参考资料。

## 入库与质量规则

1. 先定义分析任务和变量类型，再选择图形。
2. 公式、统计假设、分箱规则、归一化方式和参数必须可追溯。
3. 区分描述统计、统计估计、假设检验和因果推断。
4. 标明尺度、基线、单位、样本量、时间范围、缺失值处理和不确定性。
5. 真实案例记录作者、来源、许可和访问日期；可合法再分发的数据放入案例的 data 子目录。
6. 不把示意图当作真实数据，不编造数据集、计算结果、出处或制作工具。
7. 复杂图形只有在增加分析价值时才采用，并讨论误读风险。
