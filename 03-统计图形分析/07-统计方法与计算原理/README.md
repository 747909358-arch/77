# 统计方法与计算原理

统计图形负责表达，统计方法负责定义如何从样本或总体中计算、估计和比较。

## 知识模块

1. 描述统计：计数、比例、总和、均值、中位数、众数、分位数、方差、标准差、四分位距。
2. 分布与概率：频数分布、概率密度、累积分布、常见分布族、抽样分布。
3. 关联分析：协方差、Pearson 相关、Spearman 秩相关、列联表与关联度量。
4. 回归与趋势：线性回归、非线性拟合、平滑、残差诊断。
5. 抽样与推断：抽样误差、标准误、置信区间、假设检验、效应量。
6. 时间序列：趋势、季节性、自相关、移动平均、增长率、同比与环比。
7. 多变量分析：标准化、主成分分析、聚类、距离度量、降维。

每个方法条目应记录研究问题、适用数据、定义与公式、参数/假设、计算步骤、结果解释、可视化搭配、局限和参考来源。区分描述性统计、模型估计与因果推断。
